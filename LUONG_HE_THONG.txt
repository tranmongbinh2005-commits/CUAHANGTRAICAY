 II. LUỒNG ĐỊNH TUYẾN (ROUTING)
────────────────────────────────────────────────────────────────

Mọi request đi qua: index.php
  → Đọc $_GET['url']
  → Tách URL: /{Controller}/{Action}/{id?}
  → Ví dụ: /CUAHANGTRAICAY/Product/show/3
           Controller = ProductController
           Action     = show($id=3)

Cơ chế:
  1. index.php đọc $_GET['url']
  2. Tách thành [controller, action, params]
  3. Khởi tạo class {Controller}Controller
  4. Gọi phương thức action($params)
  5. Controller load View tương ứng qua include

Cơ chế API Routing (khi URL bắt đầu bằng /api/):
  1. Chuyển hướng đến {Tên}ApiController.
  2. Xác định phương thức dựa trên HTTP Method (GET, POST, PUT, DELETE).
  3. Controller trả về dữ liệu dạng JSON.

Hằng số BASE_URL được định nghĩa trong index.php,
dùng cho tất cả href và Location redirect.

          → list.php: Lưới card sản phẩm
                - Tìm kiếm theo tên (client-side JS)
                - Lọc theo danh mục (client-side JS)
                - Nút "Thêm vào giỏ" / "Xem chi tiết"
                - Nút "Sửa" / "Xóa" (chỉ hiện với admin)


┌─────────────────────────────────────────────────────────┐
│  LUỒNG 2: GIỎ HÀNG & THANH TOÁN (ĐẶT HÀNG)           │
└─────────────────────────────────────────────────────────┘

  [Bước 1] Thêm vào giỏ hàng
    Nhấn "Thêm vào giỏ" (từ list.php hoặc show.php)
      └─→ GET /Product/addToCart/{id}
            └─→ ProductController::addToCart($id)
                  → Lấy sản phẩm từ DB (getProductById)
                  → Nếu đã có trong giỏ: quantity++
                  → Nếu chưa có: thêm mới vào $_SESSION['cart']
                  → Redirect về trang TRƯỚC ĐÓ (HTTP_REFERER)
                    ※ KHÔNG tự chuyển sang trang giỏ hàng
                    ※ Nếu referer là cart/checkout → về /Product/

  [Bước 2] Xem giỏ hàng
    Nhấn "Giỏ hàng" trên Navbar (hoặc tự vào)
      └─→ GET /Product/cart
            └─→ ProductController::cart()
                  → Đọc $_SESSION['cart']
                  → cart.php: Hiển thị danh sách sản phẩm
                        - Ảnh, tên, đơn giá, số lượng (+/-), thành tiền
                        - Xóa từng sản phẩm
                        - Cập nhật số lượng → POST /Product/updateCart
                        - Tóm tắt đơn hàng (tổng tiền, miễn phí ship)
                        - Nút "Tiến hành thanh toán"

    Cập nhật số lượng:
      POST /Product/updateCart
        → quantities[product_id] = số lượng mới
        → Nếu quantity <= 0: xóa khỏi giỏ
        → Redirect về /Product/cart

    Xóa sản phẩm:
      GET /Product/removeFromCart/{id}
        → unset($_SESSION['cart'][$id])
        → Redirect về /Product/cart

  [Bước 3] Thanh toán (Checkout)
    Nhấn "Tiến hành thanh toán"
      └─→ GET /Product/checkout
            └─→ ProductController::checkout()
                  → Nếu giỏ trống: redirect về /Product/cart
                  → Nếu đã đăng nhập:
                      AccountModel::getAccountByUsername($_SESSION['username'])
                      → Lấy $userInfo (object) từ bảng `account`
                  → checkout.php:
                        - Form giao hàng tự động điền từ $userInfo:
                            customer_name ← $userInfo->fullname
                            phone         ← $userInfo->phone
                            email         ← $userInfo->email
                            address       ← $userInfo->address
                        - Ưu tiên $_POST nếu user đã nhập (khi có lỗi validation)
                        - Chọn phương thức thanh toán: COD / Chuyển khoản
                        - Ghi chú giao hàng (TÙY CHỌN, để trống được)
                        - Tóm tắt giỏ hàng bên phải

  [Bước 4] Xác nhận đặt hàng
    Submit form → POST /Product/processCheckout
      └─→ ProductController::processCheckout()
            → Validate bắt buộc:
                customer_name (không rỗng)
                phone         (không rỗng)
                address       (không rỗng)
                notes         → TÙY CHỌN (để trống vẫn đặt được)
            → Nếu giỏ trống: redirect về /Product/cart
            → Nếu hợp lệ:
                OrderModel::createOrder(..., $cart)
                  → BEGIN TRANSACTION
                  → INSERT vào bảng `orders`
                  → INSERT từng sp vào bảng `order_details`
                  → COMMIT → trả về $order_id
                → Xóa $_SESSION['cart']
                → Lưu $_SESSION['order_success'] = [order_id, customer_name, phone, address, total_price, payment_method]
                → Hiển thị success.php (hóa đơn thành công)
            → Nếu lỗi DB:
                → Lưu thông báo lỗi vào $_SESSION['order_error_debug']
                → Load lại $userInfo (để form tự điền lại)
                → Hiển thị lại checkout.php kèm thông báo lỗi

  [Bước 5] Trang thành công
    success.php:
      → Đọc $_SESSION['order_success']
      → Hiển thị hóa đơn: mã đơn hàng (#FS-XXXXXX), tên KH, SĐT, địa chỉ,
        phương thức thanh toán, tổng tiền
      → Nếu chuyển khoản: hiện thông tin ngân hàng + QR
      → unset($_SESSION['order_success']) sau khi hiển thị
      → Nút "Quay lại trang sản phẩm"

 IV. PHÂN QUYỀN HỆ THỐNG (SESSION & ROLE)

  Vai trò:
    admin  →  Toàn quyền (CRUD sản phẩm, danh mục, xem đơn hàng)

    - checkout.php: Auto-fill nếu đã đăng nhập (isLoggedIn)
    - Controller  : Guard đầu mỗi action admin (isAdmin → exit)

 VI. GIỎ HÀNG (SESSION-BASED)
────────────────────────────────────────────────────────────────

  Giỏ hàng lưu trong $_SESSION['cart'], không cần CSDL.

  Cấu trúc:
    $_SESSION['cart'] = [
        product_id => [
            'name'     => 'Táo Mỹ',
            'price'    => 50000,
            'quantity' => 2,
            'image'    => 'uploads/tao.jpg'
        ],
        ...
    ]

  Nghiệp vụ:
    addToCart($id)        → Thêm/tăng SL; redirect về trang trước
    cart()                → Đọc session, render cart.php
    updateCart()          → POST quantities[] → cập nhật/xóa nếu SL=0
    removeFromCart($id)   → Xóa 1 sản phẩm khỏi giỏ
    checkout()            → Đọc giỏ + lấy userInfo từ DB → checkout.php
    processCheckout()     → Validate → createOrder() → clear cart → success
    
  Vòng đời:
    Thêm vào giỏ  → session['cart'] được cập nhật
    Cập nhật SL   → POST updateCart → session['cart'] thay đổi
    Đặt hàng xong → unset(session['cart'])


────────────────────────────────────────────────────────────────
 VII. AUTO-FILL THÔNG TIN CHECKOUT
────────────────────────────────────────────────────────────────

  Khi người dùng đã đăng nhập và vào trang /Product/checkout:
  
  ProductController::checkout()
    → isLoggedIn() == true
    → AccountModel::getAccountByUsername($_SESSION['username'])
       → SELECT * FROM account WHERE username = ?
       → Trả về object (PDO::FETCH_OBJ): $userInfo
    → Truyền $userInfo vào view checkout.php

  checkout.php sử dụng:
    Họ tên:   $userInfo->fullname  (hoặc $_POST nếu có lỗi form)
    SĐT:      $userInfo->phone
    Email:    $userInfo->email
    Địa chỉ:  $userInfo->address

  Ưu tiên:
    1. $_POST[...] – nếu user đã submit form nhưng có lỗi validation
    2. $userInfo->... – nếu là lần đầu vào trang (chưa submit)
    3. '' – nếu chưa đăng nhập hoặc tài khoản chưa điền thông tin

  Quan trọng:
    - $userInfo là OBJECT (PDO::FETCH_OBJ), truy cập bằng ->field
    - Dữ liệu query TRỰC TIẾP từ DB mỗi lần load → cập nhật DB là
      checkout tự phản ánh ngay, không cần logout/login lại

 X. GHI CHÚ KỸ THUẬT QUAN TRỌNG
────────────────────────────────────────────────────────────────

  1. PDO ERRMODE_EXCEPTION bật trong database.php
     → Mọi lỗi SQL đều throw exception, không âm thầm thất bại

  2. OrderModel::createOrder() dùng TRANSACTION
     → INSERT orders → INSERT order_details (nhiều dòng)
     → Nếu bất kỳ bước nào lỗi → ROLLBACK toàn bộ

  3. order_details KHÔNG có FK cứng vào bảng product
     → Xóa sản phẩm không ảnh hưởng đến lịch sử đơn hàng
     → product_name lưu tên sp tại thời điểm đặt hàng

  4. Ảnh sản phẩm:
     → Lưu vào /uploads/, tối đa 10MB
     → Định dạng: jpg, jpeg, png, gif
     → Khi sửa: giữ ảnh cũ nếu không upload mới

  5. Giỏ hàng thuần Session (không DB):
     → Xóa khi đặt hàng thành công (unset cart)
     → Xóa khi session hết hạn / đóng trình duyệt

  6. Auto-fill checkout:
     → Dùng PDO::FETCH_OBJ → $userInfo là Object
     → Truy cập: $userInfo->fullname, ->phone, ->email, ->address
     → Query mỗi lần load trang (luôn đồng bộ với DB)

  7. addToCart() redirect về HTTP_REFERER:
     → Người dùng KHÔNG bị tự chuyển sang giỏ hàng
     → Chỉ chuyển sang giỏ khi tự nhấn "Giỏ hàng" trên Navbar

  8. processCheckout() khi lỗi:
     → Load lại $userInfo từ DB để auto-fill vẫn hoạt động
     → Hiển thị thông báo lỗi chi tiết (từ session order_error_debug)


────────────────────────────────────────────────────────────────
 IV. LUỒNG RESTful API (POSTMAN / TÍCH HỢP)
────────────────────────────────────────────────────────────────

Hệ thống cung cấp sẵn các API theo chuẩn RESTful để có thể can thiệp
(thêm, sửa, xóa, lấy danh sách) từ Postman hoặc phần mềm bên thứ 3.

1. API Sản phẩm (/api/product)
   - Lấy danh sách   : GET    /api/product
   - Lấy chi tiết    : GET    /api/product/{id}
   - Thêm sản phẩm   : POST   /api/product (Payload JSON: name, description, price, category_id)
   - Cập nhật        : PUT    /api/product/{id} (Payload JSON)
   - Xóa sản phẩm    : DELETE /api/product/{id}

2. API Danh mục (/api/category)
   - Lấy danh sách   : GET    /api/category
   - Lấy chi tiết    : GET    /api/category/{id}
   - Thêm danh mục   : POST   /api/category (Payload JSON: name, description)
   - Cập nhật        : PUT    /api/category/{id} (Payload JSON)
   - Xóa danh mục    : DELETE /api/category/{id}

Lưu ý: Luồng API này hoạt động độc lập và song song với giao diện Web (UI).
Người dùng có thể vừa dùng web bình thường, vừa dùng Postman để thao tác API, 
và thao tác trực tiếp trên Database. Tất cả đều đồng bộ ngay lập tức.
